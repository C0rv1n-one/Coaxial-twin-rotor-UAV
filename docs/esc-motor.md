## 2. 接线

### 2.1 飞控侧

SPRacingF3 底部为「舵机 / 电调输出端 1–8」，每格 3 脚：`S`(信号) / `+`(5V) / `-`(GND)。

| 电调 | 信号 | 地 |
|---|---|---|
| ESC #1（上桨） | MOTOR 1 `S` → **A06** | MOTOR 1 `-` |
| ESC #2（下桨） | MOTOR 2 `S` → **A07** | MOTOR 2 `-` |

规则：

- **只接 `S` 和 `-`**，中间的 `+` 空着（电调无 BEC，不向飞控回灌 5V）。
- **禁止使用 MOTOR 7 / MOTOR 8**：对应 A02 / A03，已分配给 USART2 的 iBUS 摇杆信号。
- 电池负极、电调 GND、飞控 GND 必须共地。
- 电池端并 **470µF/25V** 电解电容（6S 用 35V）。

### 2.2 电调侧

| 电调端 | 接到 |
|---|---|
| 信号线（白/黄） | 飞控 MOTOR n `S` |
| GND（黑） | 飞控 MOTOR n `-` |
| 遥测线（如有第三根） | 暂不接（SPRacingF3 三个 UART 已占满） |
| 粗红 / 粗黑 | 电池 + / −（经 XT60 或分电板） |
| 三条粗线 | 电机三相，顺序无关 |

### 2.3 飞控供电

- 电调无 BEC → 飞控必须单独供电：**USB（台架）** 或 **5V UBEC（飞行）**。
- USB 与 UBEC 不要同时接。
- 可选：电池正极 → 飞控 `VBAT` 焊盘（板载分压），用于电压显示与低压告警。

## 3. 飞控设置

```
set motor_pwm_protocol = DSHOT300
save
```

- BLHeli_32 原生支持 DShot，无需油门行程校准。
- F303 + BF 4.0.6 跑 DShot300 最稳（DShot600 视 DMA 情况，可能不稳）。

电机页自检顺序：

1. 拆桨；
2. 勾选「我已了解风险」；
3. 单电机 1050 油门试转 2 秒，确认是 M1 还是 M2；
4. 检查转向，转向反了就**对调任意两根电机线**，或在 BLHeliSuite32 里把 `Motor Direction` 改 `Reversed`。

## 5. 未来目标：同轴双桨 + 斜盘

### 5.1 控制原理

同轴双桨（共轴反转）的三个控制通道：

| 通道 | 实现方式 | 作用 |
|---|---|---|
| 总距 collective | 两桨总距同步变化（或转速同步） | 升降 / 承载 |
| 偏航 yaw | 上下桨**差速**（反扭矩差） | 偏航 |
| 俯仰/横滚 pitch/roll | **斜盘倾转** → 桨盘倾斜 → 力矩 | 姿态 |

关键：**两个桨在同一根轴上，差速只能产生偏航**；俯仰和横滚必须靠斜盘
（周期变距）或整体倾转旋翼头。这就是为什么普通多旋翼固件（Betaflight）做不了。

### 5.2 需要的硬件

- 2 路电调（未来 40–45A，BLHeli_32）
- 2–3 个斜盘舵机（数字金属齿，333Hz），独立 5–6V BEC（≥3A，不要从飞控 5V 取）
- 斜盘机构、主轴、上下桨固定件、单向轴承
- 上下桨：上桨 CW、下桨 CCW，间距 ≥ 0.4–0.5 倍桨径（减小下桨效率损失）
- 等径时扭矩大致对半，下桨效率偏低，需要略增下桨桨距或转速来配平

### 5.3 固件路线

| 方案 | 说明 | 结论 |
|---|---|---|
| Betaflight | 无同轴直升机混控，`mixer CUSTOM` 也凑不出斜盘 | 仅用于台架验证电机/电调 |
| **ArduPilot Copter** | 提供 CoaxCopter 机型，原生支持双桨 + 斜盘舵机 | **推荐**；但 SPRacingF3（F303, 256KB）装不下，需换 F405/F7 |
| 自写混控（STM32） | 缺陀螺仪姿态数据，等于自研飞控 | 不建议 |

ArduPilot 相关（刷完固件后逐项核对，不同版本参数名略有差异）：

- `FRAME_CLASS = 9`（CoaxCopter）
- 输出映射在 `SERVOx_FUNCTION` 里配：两个电调 + 斜盘舵机，以 Mission Planner 的 Servo Output 页为准
- 斜盘类型、总距范围等属 `H_` 系列参数
- 遥控输入：优先 SBUS / CRSF；iBUS 需较新固件才支持

若 ArduPilot 端 iBUS 不通，接收机（STM32）加一路 SBUS 输出即可（约 50 行），
接线不用改，USART2 那一根线照用。

### 5.4 载货的物理现实

桨盘载荷 = 起飞重量 / 双桨桨盘面积：

| 桨径 | 双桨桨盘面积 | 3kg 起飞重量下桨盘载荷 | 评价 |
|---|---|---|---|
| 5" | ≈0.025 m² | ≈118 kg/m² | 过高，航时 2–3 分钟 |
| 8" | ≈0.065 m² | ≈46 kg/m² | 可用 |
| 10" | ≈0.101 m² | ≈30 kg/m² | 好 |
| 12" | ≈0.146 m² | ≈21 kg/m² | 很好 |

结论：**1960KV + 5 寸是「推力大、航时短」的路线**，适合验证与轻载（≤0.5kg）；
真要载货，应走**低 KV + 大桨**（如 2810/2812 800–1000KV + 10–12 寸，4–6S）。
